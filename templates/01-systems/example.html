FOUNDATIONS

Core principles

Every decision in this template traces back to a small set of rules. The grid is not decoration — it is the contract that keeps every slide aligned.

  • GRID // 32PX BASELINEAll spacing is a multiple of 32px. No arbitrary values.
  • TYPE // MONOSPACE FIRSTJetBrains Mono carries structure; Inter supports reading.
  • COLOR // TERRACOTTA ACCENTOne accent color, used only for emphasis and markers.
  • BORDER // 1PX HAIRLINESeparation comes from lines, never from shadows.

COMPARISON

Two approaches

A — RIGID

Fixed grid

Predictable alignment at every breakpoint. Best for technical content, data-heavy slides, and documentation where consistency matters more than surprise.

RADIUS: 0PX · SHADOW: NONE
B — FLUID

Elastic spacing

Spacing scales with viewport while maintaining proportional rhythm. Best for narrative decks where breathing room changes with screen size.

RADIUS: 0PX · SHADOW: NONE
